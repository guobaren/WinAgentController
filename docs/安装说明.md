# WinAgentController 安装说明

WinAgentController 是面向 AI Agent 的 Windows 远程控制工具：命令执行、持久任务、文件传输、桌面 UI 自动化与浏览器控制，全部经 TLS 指纹固定与配对认证保护。

本压缩包为完整安装介质（7 个可执行文件 + 12 个部署/运维脚本）。详细技术文档见同目录 `README-详细版.md`。

## 系统要求

- Windows 10/11 x64（被控机），网络可达
- 安装需要**管理员权限**（会弹出一次 UAC 确认）

## 快速安装（推荐）

1. 将本压缩包解压到被控机任意目录（如 `C:\Temp\RemoteController`）
2. （可选）用记事本编辑 `RemoteController.Agent.config.json` 调整配置（见下文）
3. **双击 `Setup-RemoteControllerAgent.cmd`**
4. 在弹出的 UAC 窗口点"是"
5. 等待窗口显示 `[OK] RemoteController Agent setup completed successfully.`

首次运行若出现 SmartScreen"未知发布者"提示，点"仍要运行"即可（当前版本未做代码签名）。

## 配置文件说明（RemoteController.Agent.config.json）

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `InstallPath` | `C:\Program Files\RemoteController` | 程序安装目录 |
| `DataRoot` | `C:\ProgramData\RemoteController` | 状态数据目录（身份、配对、任务、日志） |
| `TcpPort` | `43001` | Agent 控制端口 |
| `UiUser` | 当前用户 | UI 自动化登录用户 |
| `RegenerateIdentity` | `false` | 保持现有身份与配对；**除非故意重置，不要改成 true** |
| `ArmPairing` | `true` | 安装后生成 10 分钟有效的一次性配对码 |

## 安装后如何连接

1. 记录安装窗口输出的**设备 ID**、**TLS SHA-256 指纹**和**一次性配对码**（配对码 10 分钟有效）
2. 在控制端电脑用 `Rc.Cli.exe`（可从本包取出，或从 [GitHub Releases](https://github.com/guobaren/WinAgentController/releases) 获取）执行：

```powershell
.\Rc.Cli.exe probe  <被控机IP>:43001 --fingerprint <SHA256指纹> --text
.\Rc.Cli.exe pair   <被控机IP>:43001 --fingerprint <SHA256指纹> --code <配对码> --text
```

配对成功后即可执行命令、传输文件、控制桌面与浏览器（详见详细版文档）。

## 给 AI Agent 使用（推荐）

本工具专为 AI Agent 设计。如果希望通过 Agent 操作被控机（配对、执行命令、管理任务、文件传输、UI/浏览器控制、远程升级），**建议同时安装项目 Skill**，Agent 会按 Skill 指引完成指纹核验、配对、操作与健康验收。**本压缩包已附带该 Skill**（`\.agents\skills\operate-win-agent-controller\`），解压后直接复制即可，无需联网获取：

```powershell
$source = '<解压目录>\.agents\skills\operate-win-agent-controller'
$destination = Join-Path $env:USERPROFILE '.codex\skills\operate-win-agent-controller'
Copy-Item -LiteralPath $source -Destination $destination -Recurse
```

后续对话中通过 `$operate-win-agent-controller` 调用即可。

该 Skill 是 Agent 操作指南，不替代本包的一键安装；仅手动使用时不需安装。

## 升级

- **已安装的被控机**：由控制端执行 `rcctl update apply <IP:port> --fingerprint <SHA256> --package <解压目录> --wait`（完整包目录，含全部 exe 与脚本）
- **本地重装/刷新**：重新双击 `Setup-RemoteControllerAgent.cmd`（保持 `RegenerateIdentity=false`，不会清除配对）
- 升级成功后 Agent 会自动清理更新暂存数据，只保留终态记录

## 卸载

双击 `Uninstall-RemoteController.cmd`（或在管理员 PowerShell 中运行 `.\Uninstall-RemoteController.ps1`；加 `-KeepData` 保留数据目录）。

## 安全注意事项

- 仅在您拥有明确授权的设备上使用；本工具可执行任意命令与提权操作
- **必须通过可信渠道核对 TLS 指纹**（如被控机控制台），不要只相信局域网发现结果
- 配对码、私钥、指纹不要写入聊天记录或日志
- 文件服务默认限制在运行账户的用户目录；生产环境建议将 `RC_AGENT_FILE_ROOT` 设为专用目录

## 包内文件校验

`SHA256SUMS.txt` 包含本包全部文件的 SHA-256 哈希，可用 `Get-FileHash` 核对：

```powershell
Get-FileHash .\Rc.Agent.exe -Algorithm SHA256
```

`VERSION.txt` 记录版本号、来源 commit 与构建时间，反馈问题时请一并提供。
