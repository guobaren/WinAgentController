- `Rc.TestRemoteControl.exe` 仅用于已授权可信测试网，不得加入 `artifacts/publish` 或作为正式远程控制安全边界；新版 `listen` 会自动请求 UAC，必须确认提示后再开始升级测试。由它启动可见 UI 程序时必须显式降至普通完整性。

## 人工恢复（目标桌面管理员 PowerShell）

在 `192.168.3.50` 的目标桌面打开“以管理员身份运行”的 PowerShell，执行：

```powershell
$ErrorActionPreference = 'Stop'
$install = 'C:\Program Files\RemoteController'
$data = 'C:\ProgramData\RemoteController'
$updateRoot = Join-Path $data 'updates'
$payload = Get-ChildItem -LiteralPath $updateRoot -Directory |
    Sort-Object LastWriteTime -Descending |
    ForEach-Object { Join-Path $_.FullName 'payload' } |
    Where-Object { Test-Path -LiteralPath (Join-Path $_ 'Update-RemoteController.ps1') } |
    Select-Object -First 1

if ($null -ne $payload) {
    & "$env:SystemRoot\System32\WindowsPowerShell\v1.0\powershell.exe" `
        -NoLogo -NoProfile -ExecutionPolicy Bypass -File (Join-Path $payload 'Update-RemoteController.ps1') `
        -SourcePath $payload -InstallPath $install -DataRoot $data -TcpPort 43001
    if ($LASTEXITCODE -ne 0) { throw "Update script exited with code $LASTEXITCODE." }
}
else {
    foreach ($service in 'RemoteControllerBroker', 'RemoteControllerAgent') {
        Start-Service -Name $service -ErrorAction Stop
    }
    $task = Get-ScheduledTask -TaskName 'RemoteControllerUiAgent' -ErrorAction SilentlyContinue
    if ($null -ne $task) { Start-ScheduledTask -TaskName $task.TaskName }
}

Get-Service -Name RemoteControllerBroker,RemoteControllerAgent |
    Select-Object Name,Status
```

如果脚本提示找不到安装文件，先确认 `C:\Program Files\RemoteController\Rc.Agent.exe` 是否存在；若安装目录为空但同级存在 `.RemoteController.update-backup-*`，不要删除该备份，先把结果发回。恢复后从控制端执行 `Test-NetConnection 192.168.3.50 -Port 43001`，再用原先已核对的指纹运行 `probe`；不要重新生成身份或删除 `C:\ProgramData\RemoteController`。
