## 特殊指令

- 常规安装、刷新和升级必须保持 `RegenerateIdentity=false`；除非用户明确要求重置身份，否则不得解除配对、轮换证书或删除 DataRoot。
- UDP 发现只用于定位；只有成功完成显式固定指纹连接后，才允许用同设备 ID 的新指纹替换旧档案。
- 不在聊天、普通日志或源码中记录一次性配对码、控制端私钥、Agent 私钥或完整固定指纹。
- 更新成功必须同时核对 detached result、固定指纹 probe、无副作用认证命令、服务/UI 状态及相关哈希；上传完成或 bootstrap job 结束不能单独证明升级成功。
- 测试必须读取实际输出并逐项断言；构建成功、退出码 0、模拟测试或服务启动不能替代真实链路/UI 验收。
- UI 验收要求活动且解锁的普通用户桌面；鼠标 move/button/wheel 必须分开操作和验证，默认步骤间隔为 400 ms。
- `Rc.TestRemoteControl.exe` 只允许用于已授权可信测试网，不进入正式发布包，也不构成正式认证边界。
- `target refresh` 首次启用发现防火墙规则时需要管理员权限。
- 工作区已有大量相关未提交修改；后续编辑必须保留这些修改并在提交前整体复核。
