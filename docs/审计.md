## Known Issues / 风险

- `src/Rc.Agent/Updates/UpdateService.cs:311-319`：超时会阻止永久 `Applying`，但磁盘完全不可写时状态文件本身也可能无法持久化；仍需隔离目标故障注入和回滚验收。
- `src/Rc.Cli/Commands/TargetCommand.cs:150-157`：`target refresh` 会先确保发现防火墙规则；普通终端首次运行可能失败，需要管理员权限。
- `scripts/RemoteController.Agent.config.json:8`、`scripts/Setup-RemoteControllerAgent.ps1:216`：身份重建会轮换证书并破坏现有配对；常规刷新必须保持 `RegenerateIdentity=false`。
- `tools/Rc.TestRemoteControl/Program.cs:9-10`：测试恢复工具固定来源 IP 和端口且不具备正式 TLS/配对认证，只能用于已授权可信测试网，禁止进入正式发布包。
- `scripts/Test-RemoteControllerUi.ps1:214-219`：可见 UI 验收依赖活动、解锁且普通完整性的用户桌面；锁屏、UAC 安全桌面、焦点变化或高完整性测试窗口会导致失败。
