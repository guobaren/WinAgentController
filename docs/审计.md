## Known Issues / 风险

- `src/Rc.Agent/Updates/UpdateService.cs:311-319`：超时阻止永久 `Applying`，但磁盘完全不可写时状态文件本身也可能无法持久化；仍需目标侧故障注入和回滚验收。
- `src/Rc.Agent/Control/TlsControlListener.cs`、`src/Rc.Cli/Security/AuthenticatedControlConnection.cs:195-224`：目录下载仍是一分片一次控制握手；`TCP_NODELAY` 已消除主导等待（达 SCP 87.5%），批量协议仅是可选演进，非阻断缺陷。
- `global.json:2-4`：`latestMajor` 允许更高 SDK；若出现明确兼容问题，必须记录证据并临时固定版本。
- `src/Rc.Cli/Commands/TargetCommand.cs:150-157`：`target refresh` 首次启用发现防火墙规则需要管理员权限。
- `scripts/RemoteController.Agent.config.json:8`、`scripts/Setup-RemoteControllerAgent.ps1:216`：身份重建会轮换证书并破坏配对；常规刷新必须保持 `RegenerateIdentity=false`。
- `tools/Rc.TestRemoteControl/Program.cs:9-10`：无正式 TLS/配对认证，仅限已授权可信测试网，禁止进入正式发布包。
- `scripts/Test-RemoteControllerUi.ps1:214-219`：可见 UI 验收依赖活动、解锁的普通完整性桌面；锁屏/UAC 安全桌面/焦点变化会导致失败。
