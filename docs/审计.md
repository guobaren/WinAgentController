- `scripts/RemoteController.Agent.config.json:8` 与 `scripts/Setup-RemoteControllerAgent.ps1:148` 现默认 `RegenerateIdentity=false`；只有显式改为 `true` 才会解除旧配对并轮换 TLS 身份。
- `global.json:3` 固定 SDK 8.0.422，但本机仅安装 10.0.301；本轮完整发布、Agent 141/141 和完整套件 277/277 使用仓库外 SDK 10.0.301 workaround，仍需在固定 SDK 下复跑。
- `scripts/Setup-RemoteControllerAgent.ps1:216` 在身份重建路径发出警告，但操作者仍需在执行前确认是否允许破坏现有配对。
- `scripts/Test-RemoteControllerUi.ps1:214` 至 `:219` 依赖活动桌面上的真实滚轮反馈；锁屏、输入焦点变化或旧测试程序都会导致与本机结果不同，必须逐项核对实际状态。
- 标准升级生命周期缺陷已由独立 SYSTEM runner 修复；此前 `InterruptedByReboot`、任务参数引用失败和非法路径值三类失败记录保留为回归边界，最终成功会话单独记录。
- 本次 TLS 身份变化已由用户明确发起重新配对并成功完成；旧固定连接失败记录保留为历史安全边界，后续常规刷新仍不得自动信任再次变化的身份。
- `src/Rc.Agent/Jobs/ManagedTaskRegistry.cs:412`、`:526`：此前旧包测试任务曾因 TaskHost 未在 10 秒内打开控制管道而 `FailedToStart`；本轮额外任务已实际 `exited/0`，恢复后仍应保留一次回归。

- `src/Rc.Cli/Commands/TargetCommand.cs:14`、`:25-31`：当前目标档案命令面仅为 `add/list/use/refresh`；删除、编辑和重命名能力未实现。
