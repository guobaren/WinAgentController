## Known Issues / 风险

- `src/Rc.Agent/Updates/UpdateService.cs:311-319`：超时阻止永久 `Applying`，但磁盘完全不可写时状态文件本身也可能无法持久化；仍需目标侧故障注入和回滚验收。
- `src/Rc.Agent/Control/TlsControlListener.cs`、`src/Rc.Cli/Security/AuthenticatedControlConnection.cs:195-224`：目录下载仍是一分片一次控制握手；`TCP_NODELAY` 已消除主导等待（达 SCP 87.5%），批量协议仅是可选演进，非阻断缺陷。
- `global.json:2-4`：`latestMajor` 允许更高 SDK；若出现明确兼容问题，必须记录证据并临时固定版本。
- `src/Rc.Cli/Commands/TargetCommand.cs:150-157`：`target refresh` 首次启用发现防火墙规则需要管理员权限。
- `scripts/RemoteController.Agent.config.json:8`、`scripts/Setup-RemoteControllerAgent.ps1:216`：身份重建会轮换证书并破坏配对；常规刷新必须保持 `RegenerateIdentity=false`。
- `tools/Rc.TestRemoteControl/Program.cs:9-10`：无正式 TLS/配对认证，仅限已授权可信测试网，禁止进入正式发布包。
- `scripts/Test-RemoteControllerUi.ps1:214-219`：可见 UI 验收依赖活动、解锁的普通完整性桌面；锁屏/UAC 安全桌面/焦点变化会导致失败。
- `src/Rc.Agent`（2026-08-18 health 负例实测发现）：运行中停止 `RemoteControllerBroker` 会导致 `RemoteControllerAgent` 同时退出（实测两者均 STOPPED，rcctl 失联，需 SSH `sc start` 恢复）。升级场景两者一起停止属预期；运行中单独停 Broker 是否应保持 Agent 存活待评估（Broker 为提权通道，Agent 核心命令不依赖）。
- `tests/Rc.Agent.Tests/Jobs/ManagedTaskRegistrySchedulingAndRecoveryTests.cs`：`AbruptExternalTaskHostExitConvergesToDurableTerminalState` 偶发失败（`TaskHost exited with code -1 without a terminal status`），为外部宿主异常退出的时序敏感测试；2026-08-17 云端 CI 偶发 1 次（173/174 通过），本地与相邻 run 均通过。暂按 flaky 观察，若复现需为 TaskHost 终止→终态收敛增加重试或放宽时序。
- `tests/Rc.Agent.Tests/Control/ControlSessionIntegrationTests.cs`：`PersistedPairingCooldownBlocksPairStartAndWritesAudit` 曾因 `.tls-handshake-diagnostics.json.*.tmp` 文件锁偶发失败（2026-08-17 云端两次）。**已根治**：根因是 `LocalTlsHandshakeDiagnosticsFile.WriteAtomic`（`LocalTlsHandshakeDiagnosticsFile.cs:83-95`）无锁，并发 TLS 握手失败同时 `File.Move(overwrite)` 覆盖同一诊断文件导致 IOException 且 finally 删除异常外泄；已加静态锁串行化 + 删除异常静默，新增 32 路并发写测试（定向 2/2）。
- 云端 TaskHost 时序类测试系统性偶发（2026-08-17 三次 CI run 共 6 个失败，本地稳定）：`AbruptExternalTaskHostExitConvergesToDurableTerminalState`（TaskHost -1 无终态）、`StartedJobCanBeRefreshedAndThenReadFromItsPersistedTerminalSnapshot`（Exited vs HostCrashed）、`ManagedTaskRegistryRoutesElevatedJobThroughBrokerAndReadsPersistedLogs`（Assert.True 超时）、`NormalConcurrencyLimitQueuesTheSecondJobUntilTheFirstFinishes`（段文件长度不匹配）。**段文件竞态已根治**：根因是 `TaskHostSegmentWriter.WriteAsync`（`TaskHostRunner.cs:662`）直接写目标路径，Agent 注册扫描（`OutputSegmentStore.cs:171-179` 两次长度读取）可能命中写入中间；已改为临时文件 + `File.Move` 原子写（`.tmp-` 后缀不被 `*.seg` 枚举匹配），新增并发回归测试 `SegmentRegistrationNeverObservesPartiallyWrittenTaskHostSegments`（定向 5/5）。剩余 Exited vs HostCrashed / TaskHost -1 / 21s 超时属云端 runner 慢（Defender 扫描自包含 exe 拖慢 TaskHost 启动）导致的宿主超时敏感，仍待观察；CI 已加 Test 步骤失败重试一次兜底。
